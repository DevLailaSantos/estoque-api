# 📦 API de Estoque (`estoque-api`)

Projeto desenvolvido na disciplina de **Projeto Prático Web Back-End** (2º período de Análise e Desenvolvimento de Sistemas).

## 🎯 O que o projeto faz?
É um servidor Back-End construído com **Node.js puro** (`node:http`) que recebe pedidos via internet (requisições HTTP) e responde com dados organizados no formato **JSON**.

## 🛠️ Ferramentas Utilizadas
* **JavaScript (ES Modules)**
* **Node.js** (Módulo nativo `node:http`)
* **Git & GitHub**
